## Présentation

Application mobile de formation : cours et exercices corrigés de toutes matières, avec authentification déléguée à Clerk.

**Pourquoi ce choix.** Déléguer l'authentification à un service éprouvé permet de concentrer l'effort sur le contenu pédagogique plutôt que sur la gestion des comptes.

---

## Ce que fait le projet

- **Authentification Clerk** — inscription, connexion, sessions gérées hors du code applicatif
- Navigation par onglets Material
- Typographie Outfit via `@expo-google-fonts`
